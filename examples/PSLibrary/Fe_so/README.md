# Example for PSLibrary pseudopotential and Fe CIF (spin-orbit, non-magnetic)

This example is created with the following command.

```sh
% cif2qewan mp-13_Fe.cif cif2qewan.toml --so
```

It shares the CIF, the `cif_scf.in` from cif2cell and the TOML file with
`../Fe`, which is generated with `--so --mag`.
