# Iron (Fe) Example with PSLibrary Pseudopotentials

This example demonstrates how to generate Quantum ESPRESSO and Wannier90 input files for iron (Fe) using PSLibrary pseudopotentials with spin-orbit coupling and magnetic calculations.

## Overview

This example shows:
- **Material**: Iron (Fe) - a ferromagnetic metal
- **Pseudopotentials**: PSLibrary standard UPF files
- **Features**: Spin-orbit coupling (SOC) and magnetic calculations
- **Structure**: Body-centered cubic (BCC) iron from Materials Project

## Prerequisites

- Python 3.7+
- cif2qewan package installed
- cif2cell
- Quantum ESPRESSO (for actual calculations)
- Wannier90 (for actual calculations)

## Quick Start

### 1. Install cif2qewan

```bash
# Install from source
git clone https://github.com/wannier-utils-dev/cif2qewan.git
cd cif2qewan
pip install -e .

# Or install directly
pip install cif2qewan
```

### 2. Configure the system

Edit `input/cif2qewan.toml` to match your system:

```toml
# Path to cif2cell executable
cif2cell_path = "/path/to/cif2cell"

# Directory containing pseudopotentials
pseudo_dir = "/path/to/pslibrary"

# Path to pseudopotential list CSV
pp_list_path = "/path/to/pp_list.csv"

# K-point resolution for SCF (1/Å)
scf_k_resolution = 0.15

# Gaussian smearing (Ry)
degauss = 0.01

# pw2wannier90 configuration
[pw2wan]
write_unk = ".true."
```

### 3. Run the example

```bash
# Generate input files with SOC and magnetic calculations
cif2qewan input/mp-13_Fe.cif input/cif2qewan.toml --so --mag

# Or using Python directly (works with a cloned repo or an installed package)
python -m cif2qewan.cif2qewan input/mp-13_Fe.cif input/cif2qewan.toml --so --mag
```

## Generated Files

The script generates the following input files in the `output/` directory:

### Quantum ESPRESSO Input Files

- **`scf.in`** - Self-consistent field calculation
  - Magnetic calculation with `nspin = 2`
  - Starting magnetization: 3.0 μB/atom
  - K-point mesh: 21×21×21
  - Energy cutoffs: 40 Ry (wavefunction), 200 Ry (density)

- **`nscf.in`** - Non-self-consistent field calculation
  - Spin-orbit coupling enabled (`lspinorb = .true.`)
  - Non-collinear calculation (`noncolin = .true.`)
  - 62 bands for Wannier90
  - Dense k-point mesh for Wannier90

- **`pw2wan.in`** - pw2wannier90 interface
  - Writes UNK files for Wannier90
  - Generates .mmn and .amn files

### Wannier90 Input Files

- **`pwscf.win`** - Wannier90 input file
  - 18 Wannier functions (d, s, p orbitals)
  - Excludes bands 1-8 (core states)
  - Spinor calculations enabled
  - High-symmetry k-path for band structure

### Band Structure Files

- **`band/`** directory contains:
  - `nscf.in` - NSCF calculation for band structure
  - `band.in` - bands.x input for band structure

- **`check_wannier/`** directory contains:
  - `nscf.in` - NSCF calculation for convergence check

## Running the Calculations

### 1. SCF Calculation

```bash
# Run SCF calculation
cd output
mpirun -n 16 pw.x < scf.in > scf.out
```

### 2. NSCF Calculation for Wannier90

```bash
# Run NSCF calculation
mpirun -n 16 pw.x < nscf.in > nscf.out
```

### 3. Wannier90 Preprocessing

```bash
# Run Wannier90 preprocessing
wannier90.x -pp pwscf
```

### 4. pw2wannier90 Interface

```bash
# Run pw2wannier90 interface
pw2wannier90.x < pw2wan.in > pw2wan.out
```

### 5. Wannier90 Interpolation

```bash
# Set frozen window (adjust dis_froz_max based on Fermi energy)
# Edit pwscf.win: dis_froz_max = EF + 1 eV

# Run Wannier90 interpolation
wannier90.x pwscf
```

### 6. Band Structure Calculation

```bash
# Generate band structure
cd band
mpirun -n 16 pw.x < nscf.in > nscf.out
mpirun -n 16 bands.x < band.in > band.out
cd ..
```

### 7. Convergence Check

```bash
# Check Wannier90 convergence
cd check_wannier
mpirun -n 16 pw.x < nscf.in > nscf.out
cd ..
python -m cif2qewan.wannier_conv -e 5.0 -o ./ -i ./check_wannier/nscf.out
```

### 8. Band Structure Comparison

```bash
# Compare DFT and Wannier90 band structures
python -m cif2qewan.band_comp -o ./
cd ..
```

## PSLibrary vs PseudoDojo

### PSLibrary Pseudopotentials

- **Type**: Norm-conserving pseudopotentials
- **Exchange-correlation**: PBE functional
- **Energy cutoffs**: Lower (40/200 Ry vs 106/424 Ry)
- **Computational cost**: Lower
- **Accuracy**: Good for most applications

### PseudoDojo Pseudopotentials

- **Type**: Norm-conserving pseudopotentials
- **Exchange-correlation**: PBE functional
- **Energy cutoffs**: Higher (106/424 Ry)
- **Computational cost**: Higher
- **Accuracy**: Higher precision

## Troubleshooting

### Common Issues

1. **Pseudopotential not found**
   ```
   Error: Could not find pseudopotential Fe.pbe-n-rrkjus_psl.1.0.0.UPF
   ```
   **Solution**: Check `pseudo_dir` path in `input/cif2qewan.toml`

2. **cif2cell not found**
   ```
   Error: cif2cell command not found
   ```
   **Solution**: Install cif2cell and update `cif2cell_path` in config

3. **Wannier90 convergence issues**
   ```
   Warning: Poor convergence in Wannier90
   ```
   **Solution**: Adjust `dis_froz_max` in `pwscf.win`

4. **Memory issues**
   ```
   Error: Out of memory
   ```
   **Solution**: Reduce number of MPI processes or k-point mesh

### Performance Tips

1. **Parallel execution**: Use appropriate number of MPI processes
2. **Memory management**: Monitor memory usage during calculations
3. **Disk space**: Ensure sufficient space for work directories
4. **Network**: Use fast interconnect for cluster calculations
