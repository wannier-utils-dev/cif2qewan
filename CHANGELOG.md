## [0.3.0] - 2026-10-07

Rewrite of the generator as a pipeline of typed models (structure reader
-> workflow builder -> renderers -> files). The command line and the
numbers in the generated inputs are unchanged from 0.2.0; only the
formatting of two files differs. The Python API is new.

### Added
- `--reader pymatgen` reads CIF, MagCIF and the other pymatgen formats
  without cif2cell (primitive cell in the file's Cartesian frame; the SCF
  mesh follows `scf_k_resolution` with cif2cell's rule). Partially occupied
  sites are rejected.
- Magnetic structures from MagCIF files: sites of one element with
  different moments become separate species, `starting_magnetization`,
  `angle1` and `angle2` are set from the moments (in Bohr magneton, the
  convention of Quantum ESPRESSO 7.3 and later; moments below 1 Bohr
  magneton on every species are divided by the valence charge `zval` of the
  table), a collinear order follows the two-step scheme of `--mag` with the
  axis angles on every species (`lforcet` uses atomic type 1), a
  noncollinear order is noncollinear from the SCF on, and the Wannier
  functions are spinors. Moments in the file take precedence over `--mag`.
- `use_ibrav = true`: the cell as QE's `ibrav` with `A`, `B`, `C`, `cosAB`,
  `cosAC`, `cosBC` instead of `ibrav = 0` with `CELL_PARAMETERS`, as in
  mcif2qewan and cif2x. The lattice type comes from the space group (spglib),
  the structure is re-expressed in QE's vectors (moments included), and the
  SCF mesh is recomputed from them. The vectors follow QE 7.x (`ibrav =
  -13` as defined since QE 6.4.1).
- `use_symwan = true`: the Wannier90 NSCF run on the irreducible k points
  (no `nosym`, `K_POINTS {automatic}`) and `irr_bz = .true.` in `pw2wan.in`
  for symWannier (QE >= 7.3); `submit_all.sh` runs `symwannier expand` with
  `USE_SYMWAN=1`.
- `--cif2cell-output FILE` reuses a cif2cell output, `--output-dir DIR`
  selects the target directory, `-v` reports the decisions taken,
  `--version` prints the version. Errors are reported as
  `cif2qewan: error: ...` with exit status 1 instead of a traceback (also
  for `band_comp` and `wannier_conv`).
- Pseudopotential tables for the PseudoDojo NC v0.4 sets (PBE and PBEsol,
  standard and stringent) next to the v0.5 PBE tables, generated by
  `tools/pseudodojo_table.py` from the `upf` and `djrepo` archives. All
  tables carry the valence charge `zval`.
- Reference examples `examples/PSLibrary/Fe_nonmag` (no options) and
  `examples/PSLibrary/Fe_so` (`--so`); tests of the physical content of the
  inputs, of every `ibrav` value, of the MagCIF magnetism, and of the
  relation to the 0.2.0 outputs (`tests/fixtures/v0.2.0`).
- Python API: `cif2qewan.config.Config`, the readers in
  `cif2qewan.structure.readers`, `cif2qewan.workflow.builder.build_plan` /
  `plan_from_cif2cell_output`, `cif2qewan.workflow.render.render_plan` and
  `cif2qewan.workflow.output.write_rendered`; typed models in
  `cif2qewan.structure.model`, `cif2qewan.qe.model`,
  `cif2qewan.wannier90.model` and `cif2qewan.workflow.model`; the exception
  hierarchy in `cif2qewan.exceptions`.

### Changed
- `pp_list_path` and `cif2cell_path` are optional: the default table is the
  bundled `pp_psl_rrkj.csv`, the bare file name of a bundled table selects
  the installed copy, and cif2cell is taken from PATH. cif2cell itself is
  optional (`pip install '.[cif2cell]'`); it runs in a temporary directory
  with an argument list, its exit status is checked and its output is
  saved as `cif_scf.in`. An existing `cif_scf.in` is no longer reused
  implicitly; pass it with `--cif2cell-output`.
- Generated inputs: `scf.in` writes `K_POINTS {automatic}` (0.2.0 copied
  `K_POINTS automatic` from cif2cell) and `pwscf.win` lists the keywords in
  a fixed layout; every other file is byte for byte the 0.2.0 output. The
  band-path divisions are `floor(10 * L / L_min + 1e-6)` instead of
  `int(10 * L / L_min)` (identical for the examples).
- `submit_all.sh` stops at the first failing step and calls the installed
  `wannier_conv` and `band_comp` commands.
- spglib (already required by seekpath) is a declared dependency; pandas
  and docopt are no longer needed. Building needs setuptools 77 or later.
- `CONTRIBUTING.md` is replaced by a short section of the README, which
  was rewritten.

### Deprecated
- `cif2qewan.cif2qewan.main` and `python -m cif2qewan.cif2qewan`: aliases
  of `cif2qewan.cli.main`, removed in 0.4.0.

### Removed
- The 0.2.x implementation `cif2qewan.cif2qewan.qe_wannier_in` and
  `cif2qewan.cif2qewan.pseudo_list`; use the Python API above.

## [0.2.0] - 2026-09-12

### Added
- NumPy-style docstrings, comments and type hints throughout the code.
- Packaging: the scripts moved into a `cif2qewan` package that can be
  installed with `pip install .`, with `cif2qewan`, `band_comp` and
  `wannier_conv` console scripts.
- Tests: the reference examples under `examples/` are regenerated and compared
  byte for byte, plus unit tests for the scf.out/pwscf.win parsers.
- A CI workflow running those tests on Python 3.9 and 3.12.
- A `.gitignore` for Python and Quantum ESPRESSO / Wannier90 working files.
- Expanded README with installation, configuration and workflow instructions.

### Changed
- The scripts are now invoked as `cif2qewan ...` (or
  `python -m cif2qewan.cif2qewan ...`) instead of `python cif2qewan.py ...`.
- The pseudopotential CSV tables moved from the repository root into the
  `cif2qewan` package, so that they are installed with it. `pp_list_path` in
  `cif2qewan.toml` is an absolute path chosen by the user and is unaffected.
- `band_comp` and `wannier_conv` now require `-o`; both already failed
  without it.
- Python 3.9 or later is required, because of the new type hints.

### Fixed
- `cif2cell_scf_in()` used `sys.argv[1]` instead of its `cif_file` argument.
- `read_set_system()` now raises instead of continuing with an empty system
  when ntyp/nat cannot be read from the cif2cell output.
- `submit_all.sh` started with a Python docstring, which bash tried to run as
  a command.
- `matplotlib.use("Agg")` is called before `pyplot` is imported again, so
  plotting works on machines without a display.

- The license changed from GPLv2 to MIT, with the agreement of the copyright
  holders.

### Not changed
- The numerical behaviour of the generated inputs is unchanged: both
  reference examples are reproduced exactly.
